# AIシフト作成ツール

既存のシフト表Excel（`【イオン佐野】YYYYMMスケジュール.xlsm`）の「個人シフト入力表」を、
最適化AI（Google OR-Tools / CP-SAT）で自動的に埋めるツールです。
日別シート・合計・マクロなどは今まで通りExcelの数式で動きます。

## できること

- **前の月から学習**: 完成済みの月のシフトから、スタッフごとに次の内容を読み取ります。
  - 使うシフトNO.
  - 働く曜日
  - 出勤日数
  - 連勤の長さ
- **自動作成**: 「モデル時間」の必要人時に合わせて、15分単位で人手不足・余りが少なくなるように割り当てます。
- **守るルール**
  - 休み希望（0）と確定シフト（シフトNO.）
  - 1日1シフト
  - 勤務可能なシフトと曜日
  - 最大連勤
  - 最大出勤日数
  - 月の上限時間
- **なるべく守るルール**
  - 各自の目標出勤日数
  - いつも使っているシフト
- **祝日**: 個人シフト入力表の「(祝日は1）→」行を読み、祝日は「日祝」パターンで計算します。
- **Excelを壊さない**: マクロ・画像・ボタンはそのまま残ります。書き換えるのは「個人シフト入力表」のセルだけです。

11月分で試した結果（同じ基準で比較）:

| | 人手不足の合計 |
|---|---|
| 手作りのシフト | 34.25 人時 |
| AIのシフト | 4 人時（祝日2日の昼のみ） |

## 使い方（Google Colab）

1. [AIシフト作成.ipynb](AIシフト作成.ipynb) を開き、「Open in Colab」を押します（GitHubから直接開けます）。
2. **はじめて使うとき**
   1. 完成済みの月のExcelをアップロードします。
   2. モード「学習」で実行し、`AI設定.xlsx` をダウンロードします。
   3. `AI設定.xlsx` を開いて、内容を確認・修正します（下の表を参照）。
3. **毎月の作成**
   1. 新しい月のExcelで、メインメニューの年月を変えます。
   2. 「個人シフト入力表」の先月分を消し、希望だけを入力して保存します。
   3. そのExcelと `AI設定.xlsx` をアップロードし、モード「作成」で実行します。
   4. `AIシフト完成_….xlsm` と `AIシフト_レポート.xlsx` がダウンロードされます。

「個人シフト入力表」の入力の意味:

| 入力 | 意味 |
|---|---|
| シフトNO. | その日はそのシフトで確定 |
| 0 | 休み希望（確定） |
| 空欄 | AIが決める |

先月分を消す手間を省きたいときは、「入力済みのシフトを消して全部作り直す」にチェックを入れてください。
入力済みの値をすべて無視して作り直します。

## AI設定.xlsx

**スタッフ設定シート**

| 列 | 内容 |
|---|---|
| 対象(○/×) | ○ = AIが割り当てる。× = AIは触らない（手入力のまま。人数には数える） |
| 勤務可能シフト | 例: `1,4,6`。空欄なら全シフト可 |
| 勤務可能曜日 | 例: `土日祝` |
| 目標出勤日数 | この日数に近づける |
| 最大出勤日数 / 最大時間/月 / 最大連勤 | これを超えない（扶養の上限などに使う） |
| 休日の書き方 | 休みの日に `0` を書くか、空欄にするか |

**全体設定シート**

- 計算時間
- 曜日ごとに使うモデル時間パターン（例: 金曜を「平日②」にする）
- 重み（人手不足をどれだけ嫌うか、など）

## パソコンで直接使う場合

```sh
pip install ortools openpyxl
python shift_ai.py learn    202511スケジュール.xlsm -s AI設定.xlsx
python shift_ai.py generate 202512スケジュール.xlsm -s AI設定.xlsx -o AIシフト完成.xlsm -r レポート.xlsx
```

テスト: `pip install pytest && python -m pytest -q`
